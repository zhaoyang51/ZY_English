# 复盘内容优化：以阅读讲解为中心

## 定位与交付

保留双栏、章节跳转、上一步/下一步、显示全部、词汇卡片与矩阵、收藏和导出。复盘正文直接展示讲解，不新增答题、输入框、填写笔记、自检打卡，也不以“完成任务”解锁答案。原有小标题选择题改为直接阅读对应关系与解析。

| 部分 | 内容编排 | 改动 |
| --- | --- | --- |
| 1 重点词汇 | 语境义 → 原文/题项出处 → 搭配与辨析 | 整词与完整短语匹配；去重；移除首词猜测；补充重点表达用法 |
| 2 精读与长难句 | 原句 → 主干 → 意群与译文 → 修饰/逻辑说明 | 保留四阶段阅读；增加主干速览；修订称谓缩写造成的断句错误；区分语法结构与篇章功能 |
| 3 题目复盘 | 答案 → 题型 → 原文证据 → 同义对应 → 选项偏差 | 兼容两代解析数据；补齐题号；有内容才展示相应深度分析；不以泛化套话伪装单题解析 |
| 4 语篇逻辑 | 全文主旨 → 各段功能与衔接 → 小标题对应讲解 | 重写错配的概括；补原文短引作依据；答案与理由直接显示，移除作答门槛 |
| 5 写作语料 | 表达含义 → 原文依据/改写标注 → 句式 → 例句 → 用法边界 | 修订近期年份的离题表达；补搭配、主谓一致、比较与情态说明；保留分类筛选和复制 |

## 内容审校范围

本轮通用呈现和字段验证覆盖全部 68 篇。重点按仓库中的英文全文重写 2024—2026 年 12 篇的语篇概括、段落功能、小标题对应及写作迁移，并修订 2010 Text 1 的内容错误。

近期 12 篇共补充 60 处段落证据与 36 条写作表达的用法说明。另修订 2010 Text 1/3、2011 Text 1 和 2021 Text 3 中 8 处称谓缩写误断句，保留原文及其余句子标识。

数据修订以当前项目中的英文段落为依据。不能将“内部对应关系校验通过”表述为“已经逐篇对照官方试卷确认真实性”；早期年份的其余解析仍需持续人工核对。

新增解析遵循：不补写原文没有的事实或作者态度；中文概括不添加情绪化推断；语法说明依据当前句子角色；原文引用与教学改写分开；写作例句中的演示数字不能当作文章事实。

## 验证与上线

- `node scripts/build-data.cjs`：同步年度 JSON 与主页使用的数据包。
- `node --test tests/review-content.test.cjs`：全部篇章渲染、引用对应、字段、导出和阅读模式约束。
- `node tests/browser-reading.cjs`：独立无头 Chrome 检查 1—5 各部分、逐步/全部、分类与复制、下载导出、手机和深色主题；确认没有新增填写或作答控件。需 Node 22+ 及 Chrome/Chromium，可用 `REVIEW_CHROME_PATH` 指定浏览器。
- GitHub Pages 发布前自动执行内容与渲染测试，失败时阻止本次部署。
- 本地通过后提交并推送 GitHub，确认 Pages 部署与线上文件版本。
