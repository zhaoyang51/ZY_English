# 复盘模式 1—5 内容优化

本轮围绕“能独立完成什么”重组 68 篇阅读的复盘。题目、答案和原文以仓库年度 JSON 为依据；不将程序校验视为真题来源或全部解析正确性的证明。

| 部分 | 学习产出 | 本轮改动 |
| --- | --- | --- |
| 1 词汇 | 在原句中解释词义、回忆搭配 | 去重；整词/短语匹配语境；区分原文和题项出处；取消首词猜测；保留卡片、矩阵、遮挡、收藏；增加语境回忆记录 |
| 2 精读 | 自己找主谓、划分修饰、完成翻译 | 每段自主阅读与概括；逐句先译后看拆解；译文、语法分层展开；明确参考意群不能机械一一对齐 |
| 3 题目 | 用证据解释正确项，并指出错项偏差 | 先复选与写理由，再核对定位、同义替换、逐项解析；兼容两代解析字段；不存在的深度解析不伪造；记录具体错因 |
| 4 语篇 | 概括段意，说明段际关系 | 先写全文主旨再展开参考；逐段附原文；迁移训练标明为配套练习，提交后揭晓；纠正已核实的段意错位 |
| 5 写作 | 选一个表达，写出自己的句子 | 区分原文表达与改写示例；说明模板使用边界；先仿写再看示例；检查搭配、主谓一致、数字与语气；取消满分/直接套用承诺 |

每部分提供按年份和篇章保存的学习记录及自检勾选，导出时合并个人笔记。浏览到末页不自动等同于完成五部分复盘。

## 后续内容审校标准

1. 真题原文与答案需对照可靠试卷逐年核验；本轮不宣称已完成 68 篇逐句人工审校。
2. 翻译不添加英文不存在的事实、情绪或因果；保留数量、比较对象和情态强度。
3. 语篇概括必须回指段落证据；引述者观点与作者观点分开。
4. 词性依据当前句法角色；题项表达不能标作原文原句；不依据程序匹配判断“高频”。
5. 写作改写例句明确为教学示例，不能当成真题引用或事实统计。

## 维护与验证

修改 `data/YYYY.json` 后执行 `node scripts/build-data.cjs`，同步主页实际加载的数据包及年份目录。
执行 `node --test tests/review.test.cjs` 检查所有篇章的题号、数据同步、五部分渲染、语境、导出和笔记存储。
执行 `node tests/browser-review.cjs` 在独立浏览器中检查分步/显示全部、笔记恢复、选择答案、标题匹配、模板复制、实际文件下载、手机宽度和三个主题。
GitHub Pages 部署前自动运行数据与渲染测试，通过后才发布。
