## 🎯 核心功能一览

### 1. 📝 做题模式（实战模拟与即时突破）
提供针对真题的两种不同练习节奏，满足基础精读与考前冲刺的多样化需求：

* **🔍 逐题精读（随读随测）**：
  * **段落渐进推进**：左侧阅读试卷原文，右侧针对对应段落与题目进行思维推演，随读随测。
  * **即时反馈与解析**：作答后即刻提供答案正误、考点点拨与选项深度剖析。
* **📝 盲做模考（全真模考）**：
  * **沉浸考场环境**：隐藏所有答案与解析提示，支持整卷计时连续作答。
  * **一键交卷与评分**：交卷后自动统计得分、错误率并自动沉淀至错题库。
* **深度交互与阅读辅助**：
  * **点词即查**：文章中每个英文单词均支持直接点击，即时显示音标、详细释义与真题考点搭配。
  * **文章细粒度缩放**：支持 `70% ~ 240%` 范围内的 5% 步长精细字号与视口缩放，支持一键还原。
  * **全键盘快捷导航**：全面支持键盘 `←` / `→` / `空格` 翻页切换与选项快捷键作答。

---

### 2. 🦅 复盘模式（“一石五鸟”全方位研读）
复盘无需重新答题或解锁，直接围绕真题展开五大维度的精讲拆解：

1. **重点词汇**：提取真题核心高频词，展示语境释义、出处句子与真题常见搭配辨析，支持卡片与表格视图自由切换。
2. **逐句精读**：每句话拆解为原句、主干速览、意群切分与权威译文，并附带详细语法成分说明与长难句结构拆解。
3. **题目复盘**：直观展示题型归类、题干考点、原文证据精准高亮、题干与原文的同义替换映射，以及错误选项的干扰逻辑诊断（如无中生有、偷换概念、反向干扰等）。
4. **语篇逻辑**：梳理全文中心主旨、各段落承上启下的段落功能脉络与主题句对应逻辑。
5. **写作表达**：提炼真题中的学术高级表达与地道句式（论证、因果、对比、转折等），配套教学改写范例与一键复制功能。
* **双复盘排版支持**：
  * **模式 1（系统原生复盘）**：交互式多维标签栏切换与双栏联动研读。
  * **模式 2（大观复盘）**：官方高保真图文版式复盘，支持独立缩放与快捷键浏览。

---

### 3. 🔤 单词背诵（真题语境 + 艾宾浩斯记忆）
基于科学的艾宾浩斯 9 级遗忘曲线算法打造的高效背词引擎：

* **权威词库体系**：
  * **历年真题语境核心词**：收录 2010—2026 年逐篇提炼出的重难点核心词汇。
  * **大观全量词库集成**：内置《英二单词大观·大雪深埋版》与《英二单词大观 2-4 天速成版》词库。
* **多样化背诵模式**：
  * 支持 **英译汉**（英看中）、**汉译英**（中看英）以及 **语境填空** 三种测试模式。
* **拟真交互与发音**：
  * **3D 拟真物理翻卡**：支持卡片翻转效果，沉浸式记忆。
  * **真人/TTS 语音朗读**：支持自动发音与波形反馈。
  * **真题原汁语境**：每张卡片均呈现真题原句考点上下文并高亮关键词。
  * **键盘盲打评级**：支持空格翻卡、数字键评分（不认识 / 模糊 / 掌握）与一键撤销（`↩`）。

---

### 4. 📒 专属生词本与错题归档
* **随时随地一键收藏**：在做题、阅读或复盘时，点击任何单词旁的书签图标，即可一键将其及**真题原句语境**收录进专属生词本。
* **生词本专项冲刺**：支持针对已收藏生词发起独立定向的艾宾浩斯强化背诵，消灭个人词汇盲区。
* **智能错题沉淀**：自动汇集模考作答中的错题，支持针对错误类型打标签分析。

---

### 5. 📊 学习看板与资料导出
* **学习看板（数据统计）**：
  * 自动记录学习时长、做题正确率曲线与复习完成度。
  * 实时展示单词背诵进度与掌握率分布。
* **多格式资料导出**：
  * **Anki 卡片导出**：支持一键将单篇或全部生词本导出为标准的 Anki 卡片文件（`.txt` / `.tsv`），包含例句高亮与标签，可直接导入 Anki。
  * **Markdown 讲义导出**：支持将文章复盘的五大维度内容完整导出为清晰排版的 Markdown 笔记。
