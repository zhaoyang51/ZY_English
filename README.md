# ZY_English · 考研英语二阅读与一石五鸟复盘系统

本系统收录 2010—2026 年共 17 年、68 篇阅读资料，提供精读、解题与复盘训练。原生 HTML / CSS / JavaScript，无后端依赖；学习进度和个人笔记保存在当前浏览器。

## 🌟 核心功能特性

1. **做题模式（全真考场思维推演）**：
   - 阅前须知 ➔ 先读题干 ➔ 4阶段渐进式粗读 ➔ 深度苏格拉底式选项推演与避坑解析 ➔ 全局主旨交叉验证 ➔ 最终答案。
2. **复盘模式（一石五鸟深度吸收）**：
   - **第一鸟 · 语境词汇**：卡片/矩阵、释义遮挡、整词与短语语境匹配、发音、收藏及回忆记录，区分原文和题项出处；
   - **第二鸟 · 精读与翻译**：先独立写主干和译文，再展开参考意群、句法与译文；
   - **第三鸟 · 证据与错因**：重新选答、写定位理由，再核对同义改写、逐项解析，记录错因和下一次的验证方法；
   - **第四鸟 · 语篇与迁移**：自行概括全文与各段作用，结合原文核对，再完成配套小标题练习（不是原试卷新题型）；
   - **第五鸟 · 写作与运用**：区分原文表达与改写示例，说明使用边界，支持独立仿写和短段练习。

五部分均提供自检。个人记录按年份和篇章自动保存，可随 Markdown 复盘笔记一起导出。清除浏览器存储会丢失本地记录，请通过导出保留备份。

## 开发与内容维护

直接打开 `index.html` 或通过静态服务器访问即可。按年份的 `data/YYYY.json` 是阅读数据源，主页加载 `data/all_data.js`；修改年度资料后运行：

```sh
node scripts/build-data.cjs
node --test tests/review.test.cjs
node tests/browser-review.cjs
```

最后一项使用本机 Chrome/Chromium，在独立无头浏览器中验证交互；可用 `REVIEW_CHROME_PATH` 指定浏览器路径。截图与测试导出保存在忽略目录 `scratch/review-check/`。

内容优化范围、已修订案例及后续审校标准见 [复盘优化计划](docs/REVIEW_PLAN.md)。程序校验不替代逐篇对照试卷与人工内容审校。
