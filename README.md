# ZY_English · 考研英语二 (2010-2023) 官方真题精读与一石五鸟复盘全真交互系统

本系统为考研英语二（2010—2023 年共 14 年、56 篇真题阅读）全真交互式精读、解题与复盘学习平台。

## 🌟 核心功能特性

1. **做题模式（全真考场思维推演）**：
   - 阅前须知 ➔ 先读题干 ➔ 4阶段渐进式粗读 ➔ 深度苏格拉底式选项推演与避坑解析 ➔ 全局主旨交叉验证 ➔ 最终答案。
2. **复盘模式（一石五鸟深度吸收）**：
   - **第一鸟 · 重点单词与词汇量提升**：6 列标准高频词库，涵盖词性、语境释义与考研常考多义项；
   - **第二鸟 · 逐句精读与长难句翻译**：4 阶段渐显篇章精读（完整原文 ➔ 意群划分 ➔ 逐意群直译 ➔ 标准译文），搭配主干/从句精准句法剖析卡片；
   - **第三鸟 · 题目命题思维复盘**：剖析命题人同义替换逻辑与 5 大常见干扰陷阱；
   - **第四鸟 · 语篇逻辑与新题型能力迁移**：篇章逻辑主线拆解与新题型小标题匹配训练；
   - **第五鸟 · 大作文高分写作语料库**：真题同源高分观点表达与图表/论说文满分句型模板。
